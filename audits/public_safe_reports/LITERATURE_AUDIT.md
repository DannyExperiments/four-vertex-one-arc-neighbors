# Q811 source and prior-work audit

Checked November 27, 2026. **High confidence** in the stated metric, fixed-input interpretation and the prior implication for nested independence models. **Moderate confidence** that the exact fixed-DAG counterexample is distinct from the literature inspected. The search does not establish absolute priority.

## Exact target

Harviainen, Parviainen and Sharma's UAI 2026 final proceedings paper defines the d-separation distance as the number of different Boolean answers on unordered endpoints and every conditioning set on the remaining vertices. Section 3.2, p. 2065, frames the nearest-neighbor problem as transforming a given DAG by a local operation. Conjecture 2 there names one arc insertion, deletion or reversal. Distinctness is up to Markov equivalence, so the minimum is over positive distances. The March arXiv text uses “edge” for the directed operation. The paper mentions small experiments on graphs with five vertices, without an enumeration of which representatives were edited for that conjecture. [UAI version, p. 2065](https://raw.githubusercontent.com/mlresearch/v337/main/assets/harviainen26a/harviainen26a.pdf#page=7) · [Proceedings entry](https://proceedings.mlr.press/v337/harviainen26a.html) · [Author preprint](https://arxiv.org/pdf/2603.09563#page=7) · [Pinned Q811](https://github.com/10m-u/open-problems-catalog/blob/ca8d4d44ba3db527f19f28928c240168f545ecfe/problems/statistics_data_science/experimental-design-causal-inference.md#q811)

The source discusses searching for a closest Markov equivalence class, but its local transformation is stated from the input DAG. One arc applied to any representative of the input class is a separate interpretation. The counterexample certifies the fixed-representative reading and explicitly exhibits an equivalent starting DAG whose single deletion reaches the nearest class.

## Existing theorems and boundaries

- Verma and Pearl's skeleton and unshielded-collider criterion determines Markov equivalence. Chickering's 1995 Theorem 2 connects equivalent DAGs by covered arc reversals. These preserve d-separation signatures, and this explains why a reorientation can change the available edits without changing the input signature. [Verma and Pearl](https://ftp.cs.ucla.edu/tech-report/1991-reports/910020.pdf) · [Chickering 1995](https://maxchickering.com/publications/uai95.pdf)
- Chickering's 2002 Theorem 4 proves the ordered-independence-model transformation by covered reversals and arc additions. Thus any nearest alternative with a nested signature can be realized by one addition or deletion after allowing free reorientation. An arc-addition path weakly decreases separation sets along the path, while covered reversals preserve them. More than one strict step would give a closer positive-distance intermediate. In particular every distance-one pair is nested. This is an inference from that prior theorem, not a new unconditional result for the class-level question. [Chickering 2002, Theorem 4](https://jmlr.org/papers/volume3/chickering02b/chickering02b.pdf)
- The source's restricted chain analysis compares DAGs whose skeletons are chains. The fixed input here is a triangle with a pendant vertex and its nearest witness is a star. Standard structural Hamming distance, which counts arc edits themselves, is distinct from the d-separation query distance used in the conjecture. [Source §3.2](https://raw.githubusercontent.com/mlresearch/v337/main/assets/harviainen26a/harviainen26a.pdf#page=7)

Searches covered title and author variants, final proceedings and arXiv, conjecture wording, causal network edit and inclusion-boundary results, and d-separation Hamming neighbors. No exact match for the fixed-input counterexample appeared in the works inspected. The class-level statement stays outside the general conclusion, as does the source's undirected Conjecture 1.
