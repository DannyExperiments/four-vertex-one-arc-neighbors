# Statement and full proof

There is a fixed four-vertex DAG whose minimum positive d-separation query distance is one, but whose minimum positive distance among one-arc edits is two. Isolated padding gives the gap in every larger size. Allowing a prior Markov-equivalent reorientation changes the interpretation.
